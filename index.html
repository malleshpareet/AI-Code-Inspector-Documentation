Overview

AI Code Inspector helps teams find bugs, security issues and code smells automatically — integrate via REST API, SDKs or CLI.

Key features
  • Multi-language static analysis
  • Pull request scanning & CI integration
  • Auto-fix suggestions and code explanations
  • Compliance and security rulesets

Quick Start

Three minutes to scan your first repo.

  1. Create an API key in your dashboard → Settings → API Keys
  2. Install CLI or call REST API (examples below)
  3. Inspect results in the dashboard or webhook to your CI
# install CLI
npm install -g ai-code-inspector
# or via curl + installer
curl -sSL https://install.aicodeinspector.example | sh

Guides

Detailed guides for common workflows — repository setup, CI integration, and advanced scanning.

Repository setup

Use these steps to add AI Code Inspector to existing repositories quickly:

  1. Create or fetch an API key in your dashboard
  2. Add a CI step to install the CLI and run a scan on push / pull_request
  3. Filter or fail PRs based on severity via exit codes or SARIF integration

Pull request gating

Example: fail a PR if any high severity vulnerabilities are found, or only prevent merging for 'critical' issues.

Examples

Copy-paste examples you can try in local projects or CI pipelines.

CI snippet

name: Inspect Code
on: [pull_request]
jobs:
  inspect:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run AI Code Inspector
        run: ai-inspector scan --path . --api-key ${{ secrets.AI_INSPECTOR_KEY }} --format json

API Reference

RESTful JSON API for scanning code archives, GitHub repos, or streaming files.

Start a scan

curl -X POST "https://api.aicodeinspector.example/v1/scans" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "source": {
      "type": "git",
      "repo": "https://github.com/your/repo",
      "ref": "main"
    },
    "ruleset": "default"
  }'

Response (201)

{
  "scan_id": "sc_abc123",
  "status": "queued",
  "message": "Scan queued"
}

Get results

GET /v1/scans/sc_abc123
Authorization: Bearer YOUR_API_KEY

SDKs

We provide lightweight SDKs for Node, Python and Go.

Node.js example

// install
npm i @aicodeinspector/sdk

// usage
const { Client } = require('@aicodeinspector/sdk');
const client = new Client({ apiKey: process.env.AI_INSPECTOR_KEY });

(async () => {
  const scan = await client.scans.create({ repo: 'https://github.com/you/repo' });
  console.log(scan);
})();

Security

How scans, storage, and data handling are secured; guidance for private or self-hosted deployments.

Privacy & encryption

All scan payloads are encrypted in transit. For additional isolation run the self-hosted scanner in your VPC.

CLI

Command line scanner for local projects and CI pipelines.

# scan current folder
ai-inspector scan --path . --api-key $AI_KEY

# output as sarif for security platforms
ai-inspector scan --path . --format sarif > report.sarif

FAQ

What languages do you support?

We support JS/TS, Python, Java, Go, C#, Ruby and more. See supported list in the dashboard.

How is my code kept private?

All scans are encrypted in transit. You can self-host the scanner or use private-hosting plans for full isolation.
